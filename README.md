# TREENI

Treenipäiväkirja puhelimeen (PWA). Valitse lihas kartalta, löydä liike ja kirjaa sarjat.

**Avaa:** https://mestarihannes.github.io/treeni/

## Ominaisuudet

- Oma profiili: tavoite (lihasmassa, voima, kunto, laihdutus), kokemus, treenipäivät ja välineet
- Koti-näkymä: viikon tavoite, viikkoputki, seuraava treeni ja viimeisin treeni
- Valmiit ohjelmat (koko keho, ylä- ja alakroppa, työntö–veto–jalat) kuntosalille, käsipainoille tai omalla painolla, sekä omat pohjat
- Varmuuskopio: vie ja tuo tiedot JSON-tiedostona
- Anatominen lihaskartta edestä ja takaa, miehen tai naisen malli: napauta lihasta, niin näet sen liikkeet
- Napauta lihasta: alavalikkoon sen parhaat liikkeet (1–10)
- Liikepankki (876 liikettä), haku ja välinesuodatin
- Liikkeet näytetään piirrettynä hahmoanimaationa, kohdelihas korostettuna
- Suomenkieliset ohjeet 169 yleisimmälle liikkeelle: lyhyt ohje + tarkemmat ohjeet ja vinkit
- Teemat: automaattinen, vaalea, tumma ja musta
- Liikkeen tiedot, historia, ennätykset ja kehityskäyrä
- Treenin kirjaus (kg × toistot), viime kerran ehdotukset ja lepoajastin
- Tiedot tallentuvat vain omaan laitteeseen, toimii myös ilman nettiä

## Puhelimeen

iPhone: avaa osoite Safarilla → Jaa → Lisää Koti-valikkoon.
Android: avaa Chromella → valikko → Lisää aloitusnäytölle.
